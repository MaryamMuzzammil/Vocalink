# Vocalink — From Hello to Handled.

Vocalink is a premium, high-performance AI SaaS platform designed for Pakistani SMEs. It empowers businesses to launch, configure, and manage their own AI voice agents that understand Urdu, Roman Urdu, and English.

## 🚀 Features

- **Multilingual Support**: Seamlessly handles customer calls in Urdu, Roman Urdu, and English.
- **AI Call Automation**: Automated order taking, appointment booking, and inventory checks.
- **Premium Dashboard**: Real-time analytics, call volume analysis, and conversion trends.
- **Inventory Integration**: Keep your AI agent updated with your physical stock in real-time.
- **AI Call Simulator**: Test your agent's conversational flow before going live.

## 🛠️ Technology Stack

- **Frontend**: React 19, Vite, Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Inter & Inter Tight

## 📦 Getting Started

### Prerequisites

- Node.js (Latest LTS version recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MaryamMuzzammil/Vocalink.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🎨 Design Philosophy

Vocalink follows a "Clean-White" premium aesthetic inspired by modern minimalist startups. It utilizes soft mesh gradients, glassmorphism, and purposeful micro-animations to provide a high-trust, professional experience for business owners.
